# Personal Website

Персональный веб-сайт, разработанный в рамках учебного проекта.

Сайт представляет собой интерактивную страницу-визитку с информацией обо мне, моих увлечениях и интересах. Помимо основного содержимого, на странице реализована лаборатория числа π, позволяющая визуализировать цифры, анализировать их распределение и искать заданные последовательности.

**Готовый сайт:** https://solik-fps.ru

## Возможности

### Основной интерфейс

- Адаптивный дизайн для компьютеров, ноутбуков и мобильных устройств.
- Светлая и тёмная темы оформления с сохранением выбранной темы.
- Интерактивные карточки увлечений с раскрывающимся содержимым.
- Всплывающие окна с дополнительной информацией.
- Плавные анимации появления элементов при прокрутке страницы.

### Лаборатория числа π

- **Цветной ковёр:** визуализация цифр числа π в виде сетки цветных квадратов, где каждой цифре соответствует определённый цвет.
- **Настройка визуализации:** выбор количества цифр и числа квадратов в строке.
- **Экспорт изображения:** скачивание построенного ковра в формате PNG.
- **Статистика цифр:** подсчёт частоты появления каждой цифры и отображение результатов на диаграмме.
- **Поиск последовательностей:** поиск заданного набора цифр среди первых 10 000 знаков числа π после запятой с отображением количества совпадений и позиции первого вхождения.

## Используемые технологии

- **HTML5** — структура веб-страницы.
- **CSS3** — оформление, адаптивность, темы и анимации.
- **JavaScript** — интерактивность, обработка пользовательского ввода, визуализация и поиск.
- **Canvas API** — построение цветного ковра.
- **Python** — вспомогательный скрипт для вычисления цифр π.
- **Git и GitHub** — контроль версий и хранение исходного кода.
- **Cloudflare Workers** — публикация сайта в интернете.

## Запуск проекта

Для просмотра готового сайта достаточно перейти по адресу:

https://solik-fps.ru

Для локального запуска:

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в Visual Studio Code.
3. Запустить `index.html` через локальный веб-сервер, например расширение Live Server.
4. Открыть сайт в браузере.

Локальный веб-сервер необходим для корректной загрузки файла `pi-digits.txt` через JavaScript `fetch()`.

Установка дополнительных JavaScript-библиотек не требуется.

## Структура проекта

```text
Personal_Website/
├── index.html
├── style.css
├── script.js
├── pi-digits.txt
├── images/
│   └── avatar-s.jpg
├── tools/
│   └── generate_pi.py
└── README.md
```

- `index.html` — разметка страницы.
- `style.css` — стили и адаптивное оформление.
- `script.js` — интерактивные функции сайта.
- `pi-digits.txt` — первые 10 000 цифр числа π после запятой.
- `images/` — изображения, используемые на странице.
- `tools/generate_pi.py` — вспомогательный скрипт генерации цифр π.

## Публикация

Исходный код хранится в GitHub. Публикация сайта осуществляется через Cloudflare Workers с использованием собственного домена и HTTPS.
